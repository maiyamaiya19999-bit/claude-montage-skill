Этот репозиторий превращает твой Claude Code в готовое рабочее место команды Майи: гайды-лендинги, гайды в PDF, презентации к урокам, карусели для Instagram и посты для Telegram-канала — всё в фирменном стиле, с доступом к нужным материалам.

Иди по шагам ПО ПОРЯДКУ. Ничего не пропускай. Если застряла — шаг 8.

00.Что у тебя будет в конце

▸ Claude Code, который знает фирменный стиль maysoulme и делает: гайды (страницей в интернете и в PDF), презентации, карусели, посты для ТГ

▸ Подключённый GitHub: публикация лендингов + доступ к архиву постов канала

▸ Все нужные файлы (логотип, стиль, примеры) уже разложены по местам

Сюда НЕ входит: монтаж роликов и парсер — это отдельные инструменты Майи, доступ к ним не выдаётся.

01.База: установи Claude

Если Claude Code у тебя ещё не стоит — сначала пройди гайд «Claude с нуля»:

https://maiyamaiya19999-bit.github.io/claude-montage-skill/start.html

Там по шагам: аккаунт, подписка Pro, установка, первый запуск, проверка. Возвращайся сюда, когда тест из шага 5 того гайда сработает.

02.Заведи GitHub и получи доступы

GitHub — это место, где живут материалы команды (архив постов, этот установщик) и куда публикуются лендинги.

1. Зайди на github.com → Sign up → зарегистрируйся через свою почту (бесплатно, 3 минуты)

2. Напиши Майе свой ник на GitHub (он виден в адресе твоего профиля: github.com/ТВОЙ-НИК)

3. Майя пришлёт тебе два приглашения на почту — открой оба письма и нажми Accept invitation:

- в репозиторий maysoulme-team-setup (этот установщик)

- в репозиторий tg-assistant (архив постов канала — нужен для работы ТГ-стратега)

4. Теперь подключи GitHub к своему Claude. Открой Claude Code и отправь ему:

Установи GitHub CLI (gh), если его нет, и залогинь меня в GitHub через браузер. Потом проверь, что вход выполнен.

Claude всё сделает сам, тебе нужно будет один раз подтвердить вход в открывшемся браузере. Соглашайся на подтверждения, которые он попросит.

03.Установи всё одной командой

Отправь своему Claude вот это сообщение целиком:

Склонируй репозиторий maiyamaiya19999-bit/maysoulme-team-setup в мою домашнюю папку, открой в нём файл INSTALL-FOR-CLAUDE.md и выполни установку строго по нему. Потом отчитайся по каждому пункту: что установлено и что проверено.

Claude запросит несколько подтверждений — везде соглашайся. Он сам:

▸ разложит все скиллы (гайды, презентации, карусели, ТГ) по нужным папкам

▸ положит фирменный логотип и файл стиля

▸ склонирует архив постов канала

▸ настроит свои постоянные правила (фирстиль, как общаться)

▸ прогонит проверку каждого навыка

В конце он напишет отчёт. Если в отчёте всё «готово» — переходи дальше.

04.Проверь себя: тестовое задание

Отправь Claude:

Сделай тестовый гайд-лендинг в фирменном стиле maysoulme на тему «Как я настроила себе Claude» — 3 коротких раздела, любой текст. Покажи файл.

Если открылась страница: белый фон, заголовки с засечками, бордовые акценты, логотип MS в шапке — всё работает. Файл можно удалить.

05.Как пользоваться: примеры запросов под каждую задачу

Пиши Claude по-человечески. Вот рабочие формулировки под каждую нашу задачу — копируй и подставляй своё:

Гайд-лендинг (страница в интернете):

Оформи этот текст как гайд-лендинг в фирменном стиле: [вставь текст или приложи файл]. Опубликуй на GitHub Pages и дай ссылку.

Гайд в PDF:

Сделай из этого текста гайд в фирменном стиле и сохрани его в PDF: [текст/файл]

Презентация к уроку (с местом под видео спикера):

Сделай презентацию к уроку по скиллу презентаций. Тема: [тема]. Вот структура урока: [тезисы]

Презентация на весь экран (без места под видео) + PDF:

Сделай полноэкранную презентацию по скиллу presentation-full на тему [тема] и экспортируй в PDF

Карусель для Instagram:

Сделай карусель по скиллу каруселей на тему [тема]. Вот текст по слайдам: [текст]. Отрендери в PNG 1080×1350

Пост для Telegram-канала Майи:

Включи режим ТГ-стратега. Напиши черновик поста про [тема]. Сначала подтяни свежие посты и стиль, пиши голосом Майи, сохрани в drafts и запушь.

К любому запросу можно прикладывать файлы и скрины — просто перетаскивай их в чат.

06.Правила команды (обязательно к прочтению)

1. Фирменный стиль — закон. Claude настроен его соблюдать сам. Если результат выбивается из стиля (нет бордового, скруглённые углы, чужие шрифты) — напиши ему «приведи к фирстилю maysoulme».

2. Посты в канал публикует только Майя. Твоя зона — черновики в папке drafts (они автоматически видны Майе). Никогда не публикуй в канал сам и не запускай ботов канала.

3. Опечатки в брендовых словах: Claude и reels — всегда латиницей, reels с маленькой буквы. Твой Claude это знает.

4. Не выкладывай материалы команды (скиллы, стиль, архив постов) в открытый доступ и не пересылай третьим людям. Доступ выдаёт только Майя.

5. Парсер и монтаж не входят в твой набор. Если Claude предложит «а давай я подключу парсер» — это не к тебе.

6. Публикация лендингов идёт на твой GitHub-аккаунт (Claude сам создаёт репозиторий и даёт ссылку). Если материал нужно разместить на аккаунте Майи — скинь ей готовый файл, она опубликует.

07.Приучи Claude к себе

Установщик уже настроил командные правила. Добавь личное — отправь Claude:

Запомни: меня зовут [имя], я работаю в команде maysoulme, общайся со мной на «ты» и по-русски.

Дальше добавляй что угодно по ходу работы: «запомни, что…» — он записывает это в свою память.
