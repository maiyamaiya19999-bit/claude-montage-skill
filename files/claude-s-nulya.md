# Claude с нуля: подключаем всё как у Майи (@maysoulme)

Гайд для тех, кто никогда не пользовался Claude. Иди по шагам по порядку, ничего не пропуская. В конце у тебя будет полностью настроенный ассистент, которому можно сказать «смонтируй ролик» — и он смонтирует.

**Что такое Claude:** ИИ-помощник вроде ChatGPT, от компании Anthropic. **Claude Code** — его версия для компьютера, которая умеет ДЕЛАТЬ: работать с файлами, монтировать видео, создавать документы. Как ассистент, живущий в твоём ноутбуке.

**Понадобится:** компьютер (Mac/Windows), интернет, карта для подписки, ~30 минут.

## Шаг 1. Заведи аккаунт
1. Открой сайт claude.ai
2. Нажми Sign up (регистрация)
3. Проще всего — «Continue with Google» через свою почту
4. Подтверди телефон, если попросит

⚠️ Из России: нужен VPN и зарубежная карта. У Майи есть отдельный гайд — напиши ей в телеграм слово «гайд».

## Шаг 2. Оформи подписку Pro
Бесплатной версии мало — нужна Pro (~$17–20/мес, около 2000 ₽).
1. На claude.ai: имя внизу слева → Upgrade plan
2. Выбери Pro, привяжи карту, оплати
Проверка: сверху в чате появилось Pro / выбор моделей.

## Шаг 3. Установи Claude Code
1. Зайди на claude.com/claude-code → Download
2. Mac: перетащи иконку в «Программы», запусти оттуда. Спросит «точно открыть?» — жми «Открыть»
3. Windows: «Далее» до конца установки
4. Запусти и войди В ТОТ ЖЕ аккаунт, что на шаге 1
Перед тобой окно с полем ввода внизу — это твой ассистент.

## Шаг 4. Главные правила общения
- Пиши по-человечески, без специальных команд: «создай папку», «переименуй файлы», «сделай документ»
- Он будет спрашивать разрешения перед действиями — если это то, что ты просила, жми Yes/Разрешить. Так задумано
- Файлы можно перетаскивать прямо в чат
- Что-то не так — пиши словами: «стоп», «отмени», «переделай»
- Один чат = одна задача. Новая задача — новый чат (New chat)

## Шаг 5. Проверь, что работает
Отправь Claude:
«Привет! Создай у меня на рабочем столе папку "тест" и положи в неё текстовый файл со словом "работает". Потом скажи, что сделал.»
Разреши, что попросит. Появилась папка — всё работает.

## Шаг 6. Подключи скилл монтажа
Открой страницу: https://maiyamaiya19999-bit.github.io/claude-montage-skill/
Самый простой путь: скачай там файл скилла, перетащи в чат Claude и напиши:
«установи себе этот скилл сам, создай все нужные папки и скажи, что куда положить»
Везде соглашайся с подтверждениями. Он всё сделает сам и отчитается. Потом скачай со страницы файлы шаблона (полоски, градиент, музыку, шрифты) и разложи по папкам, как там написано.

## Шаг 7. Приучи его к себе
Скажи один раз:
«Запомни: общайся со мной на "ты" и по-русски. Не переспрашивай по мелочам — делай. Я создаю контент для соцсетей, ты — мой помощник по монтажу и контенту.»
Дальше добавляй свои правила: «запомни, что субтитры люблю покрупнее» и т.д.

## Шаг 8. Если что-то не получается
- Пишет по-английски → «говори со мной по-русски, запомни это»
- Просит подписку → проверь, что вошла в аккаунт, где оплачивала Pro
- Сделал не так → скажи словами, что не так — переделает
- Завис/странный → начни новый чат и опиши задачу заново (лечит почти всё)
- Просит разрешение на непонятное → «объясни простыми словами, что хочешь сделать и зачем»
- Не находит файлы → скажи точный путь или перетащи файл в чат

## Чек-лист: всё готово, если
✓ Аккаунт claude.ai с подпиской Pro
✓ Claude Code установлен и открывается
✓ Тест из шага 5 сработал
✓ Скилл монтажа установлен, папки и файлы на месте
✓ Claude запомнил, кто ты

Всё — у тебя такой же Claude, как у Майи. Кидай видео в input, пиши ТЗ, забирай ролик из output.
